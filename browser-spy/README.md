# Browser Spy

A simple tool that demonstrates how much information is exposed just by visiting a web page.

## Features

- **Network Info**: IP address, location, ISP (via external API).
- **Browser Info**: User agent, browser name, cookies, do-not-track.
- **Hardware Info**: Screen resolution, CPU cores, GPU renderer.
- **Connection**: Network type, speed.
- **Fingerprinting**: Canvas fingerprinting demonstration.

## Privacy Note

This tool runs entirely in your browser. The only external request is to `ipapi.co` to fetch your IP address and location metadata. No data is stored or sent to any other server.
