## Structure

- Each tool/demo lives in its own subdirectory.
- Each subdirectory has a `README.md` describing the tool and the prompt used to create it.
- Each tool is typically a single, self-contained static HTML file (`index.html`).

## Deployment

This repository is automatically deployed to GitHub Pages at [vibes.diwaker.io](https://vibes.diwaker.io).
