# 3D Rubik's Cube Solver

A 3D Rubik's Cube demo with scramble, reset, and solve functionality.

## Prompt

> Let's add a 3D Rubik cube solver demo. Requirements:
> - single static HTML file
> - buttons to "reset", "scramble" and "solve" the cube
> - allow the user to rotate the cube around
> - clicking on a "face" should rotate it right, left-click should rotate it left
>
> Suggest other UX goodies or features you think would make it delightful. Maybe background sprinkles or sound when user solves the cube?

## Features

- 3D Interactive Cube (Three.js)
- Scramble, Reset, and Solve (Kociemba Algorithm)
- Interactive Controls:
    - Drag to rotate view
    - Click face to rotate Clockwise
    - Right-click (or Shift+Click) face to rotate Counter-Clockwise
- Confetti on solve
- Sound effects
